# 拾序前端 · OpenWork EE 样式接入

2026-10-14，采用用户指定的 `openwork-ee-design` Skill。

## 配置与原图

- Profile：`saas`；density：`standard`。
- 页头采用内容优先的紧凑实体标题栏；欢迎区为普通 28/34px 标题。
- 对照 Skill 原图 `01-dashboard-shell.jpg`、`05-connector-dialog.jpg`、`10-mobile-navigation.jpg`，分别用于外壳、短表单弹窗和移动导航。
- SaaS 扩展优先于 Den 源码的旧控件尺寸与排版：标准输入、按钮统一 40px / r8，正文 14/22px，控件 14/20px，辅助信息 12/18px。移动触控尺寸为 44px。
- `.ow-ee`、`data-ow-profile="saas"`、`data-density="standard"` 同时放在 `body` 上，覆盖应用及浮层。

## 组件映射

| 实际组件 | 接入方式 |
| --- | --- |
| 工作空间外壳 | 260px 白侧栏、56px 白页头、`#fafafa` 画布、`#e5e7eb` 边线 |
| 新建、保存等主操作 | `#0f172a` 深墨色、白字，使用统一 hover / active / disabled / focus 状态 |
| 次操作与列表 | 白底细描边；中性灰选中；项目加号和会话更多操作独立占位，持续可见 |
| 原生输入框与 select | 使用语义 token 映射高度、字体、边框、圆角与焦点状态 |
| 原生 `<dialog>` | 编辑弹窗 448px / r28 / p24，保留原生模态，补初始输入焦点、Tab 循环及关闭还焦 |
| 会话菜单 | 键盘方向键、Home / End、Esc 与还焦；按实际尺寸限制窗口边缘位置 |
| CopilotKit v2 | 保留官方聊天组件；通过公开 slot 与实际 DOM 属性统一消息、输入区、发送按钮和快捷键提示 |
| 搜索 | 保留 250ms 防抖，补中文组合输入、快捷键重开及过时结果保护 |
| 移动导航 | 280px 抽屉；背景 `inert`；焦点移入、Tab 循环与 Esc 还焦；菜单属于抽屉的模态 DOM 范围 |

字体由本地 `@fontsource/inter` 包加载 400 / 500 / 600 字重，没有外部字体服务请求。Chrome 实际字形检查确认英文使用 Inter，中文使用 macOS 苹方；其他系统按 token 字体栈回退。中文正文没有额外字距。

## 内容与必要差异

欢迎页保留标题、一行说明和新建任务 / 创建项目两项操作。保存、配置与 Demo 说明集中到既有帮助弹窗。根据用户界面反馈，移除 DEMO 徽标、页头模型徽标和项目会话计数；未分组会话计数保留。聊天输入区和弹窗关闭按钮取消深色外框，关闭按钮以轻灰底色保留键盘焦点反馈。

- 多行聊天 composer 使用 16px 圆角，按文本内容增高；这是聊天输入区，不使用单行表单的固定 40px 高度。
- 搜索弹窗采用 640px 的内容宽度，窄屏受 viewport 限制；编辑弹窗仍为 448px。
- 拾序标识、项目与会话的数据结构以及原有项目选择 / 展开行为保留。此次调整没有更换聊天框架或后端接口。
- 当前页面没有表格、重型设置卡片或树详情工作台，相应契约无需映射到空缺页面。

## 验证

规范 / 源码审阅与目标页面检查分开进行。目标页面在 1440×960、390×844 和 720×480 视口下完成截图与实际控件测量，后两者均无整页横向溢出。720×480 检查的是 1440×960 窗口放大 200% 时等效的布局视口，并非操作系统或浏览器原生缩放测试。

测量记录在 [openwork-ee-metrics.json](openwork-ee-metrics.json)，包含实际字体、侧栏 / 页头 / 控件 / 弹窗尺寸及页面运行错误记录。

`npm run typecheck`、`npm run build` 与 `make test-e2e` 的结果另记于 README。浏览器回归使用隔离的 3211 Web、临时 SQLite 和本地模型 fixture；真实 3210 页面仅恢复已有会话和打开 / 取消弹窗，没有发送新聊天消息，本轮没有调用真实 DeepSeek。
